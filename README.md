# ai-agent-poc
Proof-of-concept projects exploring different AI SDKs to evaluate their behavior, capabilities, and documentation quality.

## Projects

- [`google-adk-java`](google-adk-java) — Google Agent Development Kit (ADK) for Java experiments.
- [`google-adk-java-multi-tool-agent`](google-adk-java-multi-tool-agent) — Multi-tool agent built with Google ADK for Java.
